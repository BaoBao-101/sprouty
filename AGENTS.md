# Sprouty design preferences

- Use natural, restrained SVG line icons with consistent stroke weights and proportions. Prefer the existing SproutyIcon set and extend it when necessary.
- Do not use platform emoji as UI icons. Avoid glossy 3D robot artwork, excessive sparkles, gradients, shadows, or arbitrary rotations as decoration.
- Use muted botanical greens, cream, earth tones, and small accent colors. Keep illustrations purposeful and layouts readable.
- These preferences were explicitly requested by the user and apply to future design work in this repository.
